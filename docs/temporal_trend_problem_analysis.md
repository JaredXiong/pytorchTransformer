# 半监督学习时间趋势问题分析

## 问题描述

半监督学习模型的预测结果显示**污染指数随月份单调递增**的趋势，但现实中污染指数不可能随月份持续增加，而是呈现周期性波动。

## 问题根源

### 1. 数据存在长期趋势

北京 2015-2024 年空气质量数据统计：

| 年份 | AQI 均值 | 趋势 |
|------|----------|------|
| 2015 | 121.55 | - |
| 2016 | 113.42 | ↓ |
| 2017 | 101.75 | ↓ |
| 2018 | 94.95 | ↓ |
| 2019 | 86.52 | ↓ |
| 2020 | 78.45 | ↓ |
| 2021 | 77.43 | ↓ |
| 2022 | 73.69 | ↓ |
| 2023 | 82.46 | ↑ |
| 2024 | 72.49 | ↓ |

**结论**：空气质量在 2015-2024 年间持续改善，AQI 从 121.55 下降到 72.49，存在明显的**长期下降趋势**。

### 2. 时序划分导致数据分布不一致

当前的三段划分策略（`split_three_way`）：

```python
def split_three_way(self, X, y, ratios=(0.4, 0.4, 0.2)):
    """按时间顺序三段划分（不打乱），保持时序连续性"""
    n = len(X)
    n_label = int(n * ratios[0])      # 前 40%
    n_unlabel = int(n * ratios[1])    # 中 40%
    return (
        (X[:n_label], y[:n_label]),           # Labeled: 2015-2018
        (X[n_label:n_label+n_unlabel], ...),  # Unlabeled: 2018-2022
        (X[n_label+n_unlabel:], ...),         # Test: 2022-2024
    )
```

**数据分布对比**：

| 数据段 | 时间范围 | 样本数 | AQI 均值 | AQI 标准差 |
|--------|----------|--------|----------|-----------|
| Labeled | 2015-2018 | 1460 | **107.95** | 高 |
| Unlabeled | 2018-2022 | 1460 | **79.04** | 中 |
| Test | 2022-2024 | 732 | **77.43** | 低 |

**问题**：三个数据段的 AQI 分布存在显著差异，模型会学习到这种分布差异。

### 3. 模型学习时间趋势的机制

虽然 `month`/`season` 使用了 sin/cos 周期性编码：

```python
# 周期性编码（正确的做法）
df['month_sin'] = np.sin(2 * np.pi * df['month'] / 12)
df['month_cos'] = np.cos(2 * np.pi * df['month'] / 12)
```

但模型仍然可以学习到长期趋势，原因如下：

#### 3.1 隐式时间位置信息

模型输入序列包含 14 天的历史数据，这些数据本身就携带了时间位置信息：

```
训练集样本 (2015年): [aqi=120, pm2.5=80, ...]  # 高污染
测试集样本 (2024年): [aqi=60, pm2.5=30, ...]   # 低污染
```

模型会学习到：
- "当输入特征值较高时，输出也应该较高"（训练集模式）
- "当输入特征值较低时，输出也应该较低"（测试集模式）

#### 3.2 统计特征的泄露

即使使用了周期性编码，模型仍然可以通过以下方式推断时间位置：

1. **污染物浓度的季节性模式**：冬季供暖导致 PM2.5 升高，夏季臭氧升高
2. **长期趋势的残差**：虽然 month/season 是周期性的，但污染物浓度的整体水平随年份变化
3. **序列内统计特征**：14 天窗口内的均值、方差等统计量携带时间信息

#### 3.3 半监督学习的放大效应

### 4. 为什么预测随月份单调递增

模型预测显示"污染指数随月份单调递增"的原因：

1. **训练数据的时间分布**：
   - 训练集（2015-2018）的 AQI 均值较高
   - 测试集（2022-2024）的 AQI 均值较低

2. **模型的错误泛化**：
   - 模型学习到"早期数据 = 高AQI，晚期数据 = 低AQI"
   - 但 month/season 是周期性的，无法直接编码年份信息
   - 模型转而学习"月份值与AQI的统计相关性"

3. **伪标签的强化**：
   - Teacher 模型的预测带有趋势偏差
   - 伪标签选择机制（置信度过滤）可能偏好平滑预测
   - Student 模型继承并放大这种偏差

## 解决方案

### 方案 1：数据重采样（推荐）

打乱时间顺序，使用随机采样或分层采样：

```python
def split_three_way_random(self, X, y, ratios=(0.4, 0.4, 0.2)):
    """随机三段划分（打乱时间顺序）"""
    n = len(X)
    indices = np.random.permutation(n)

    n_label = int(n * ratios[0])
    n_unlabel = int(n * ratios[1])

    label_idx = indices[:n_label]
    unlabel_idx = indices[n_label:n_label + n_unlabel]
    test_idx = indices[n_label + n_unlabel:]

    return (
        (X[label_idx], y[label_idx]),
        (X[unlabel_idx], y[unlabel_idx]),
        (X[test_idx], y[test_idx]),
    )
```

**优点**：简单有效，消除时间分布差异

**缺点**：破坏时序连续性，可能影响时间依赖性学习

### 方案 2：趋势消除（推荐）

对目标变量进行差分或标准化，消除长期趋势：

```python
def detrend_data(data, method='diff'):
    """消除长期趋势"""
    if method == 'diff':
        # 一阶差分
        return np.diff(data, axis=0)
    elif method == 'zscore':
        # 按年标准化
        years = data[:, -1]  # 假设最后一列是年份
        for year in np.unique(years):
            mask = years == year
            data[mask] = (data[mask] - data[mask].mean()) / data[mask].std()
        return data
```

**优点**：保留时序结构，消除长期趋势

**缺点**：需要额外的逆变换步骤

### 方案 3：滑动窗口划分

使用滑动窗口进行交叉验证，确保每个窗口都包含不同时间段的数据：

```python
def split_sliding_window(self, X, y, n_windows=5):
    """滑动窗口划分"""
    n = len(X)
    window_size = n // n_windows
    splits = []

    for i in range(n_windows):
        start = i * window_size
        end = start + window_size
        test_idx = list(range(start, end))
        train_idx = list(range(0, start)) + list(range(end, n))
        splits.append((train_idx, test_idx))

    return splits
```

**优点**：更公平的评估，减少时间偏差

**缺点**：实现复杂，计算开销大

### 方案 4：特征工程改进

添加年份特征，让模型显式学习长期趋势：

```python
def add_year_feature(df, date_col):
    """添加年份特征（归一化）"""
    df['year'] = df[date_col].dt.year
    df['year_normalized'] = (df['year'] - df['year'].min()) / (df['year'].max() - df['year'].min())
    return df
```

**优点**：模型可以显式学习长期趋势

**缺点**：可能引入新的偏差

### 方案 5：正则化约束

添加时间相关的正则化项，惩罚模型对时间的依赖：

```python
class TemporalRegularization(nn.Module):
    """时间正则化：惩罚预测值与时间位置的相关性"""
    def __init__(self, lambda_time=0.1):
        super().__init__()
        self.lambda_time = lambda_time

    def forward(self, predictions, time_indices):
        # 计算预测值与时间位置的相关性
        time_corr = torch.corrcoef(torch.stack([predictions.mean(dim=1), time_indices]))[0, 1]
        # 惩罚高相关性
        return self.lambda_time * torch.abs(time_corr)
```

**优点**：直接约束模型行为

**缺点**：需要额外的超参数调优

## 推荐方案

**首选方案**：**方案 1（数据重采样）+ 方案 2（趋势消除）**

理由：
1. 数据重采样消除时间分布差异，是最直接的解决方案
2. 趋势消除保留时序结构，同时去除长期趋势
3. 两者结合可以有效解决时间趋势问题

**实施步骤**：

1. **修改 `split_three_way` 方法**：添加随机打乱选项
2. **添加趋势消除函数**：在数据预处理阶段消除长期趋势
3. **更新半监督训练流程**：使用新的数据划分和预处理方法
4. **验证效果**：对比修改前后的预测结果

## 验证指标

修改后需要验证以下指标：

1. **预测趋势**：预测值不应随月份单调递增/递减
2. **周期性**：预测值应显示合理的季节性波动
3. **长期趋势**：如果保留年份特征，预测值应显示合理的长期变化
4. **预测精度**：MSE/RMSE/MAE/R² 等指标不应显著下降

## 总结

半监督学习中的时间趋势问题源于：
1. 数据存在长期趋势（AQI 持续改善）
2. 时序划分导致数据分布不一致
3. 模型学习到错误的时间-目标相关性
4. 伪标签机制放大这种偏差

通过数据重采样和趋势消除可以有效解决这个问题，使模型学习到正确的季节性模式，而非虚假的长期趋势。
